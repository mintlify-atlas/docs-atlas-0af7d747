ORVIAN is a full-stack school management platform built on Laravel 12 for Dominican educational institutions. It unifies attendance tracking (facial recognition, QR, and manual), academic administration, student enrollment, teacher assignments, and WhatsApp alert communications — all within a multi-tenant architecture where every school operates in complete isolation.

## What ORVIAN Does

<CardGroup cols={3}>
  <Card title="Dual Attendance" icon="users">
    Campus-level (Plantel) and classroom-level attendance with strict cross-validation to detect hall-wandering ("pasilleo").
  </Card>
  <Card title="Three Recording Methods" icon="camera">
    Facial recognition, physical QR wristband scan, or manual roll call — all from a single interface.
  </Card>
  <Card title="Multi-Tenant Isolation" icon="shield">
    Each school's data is fully isolated. Middleware resolves tenant context automatically on every request.
  </Card>
  <Card title="Role-Based Access" icon="lock">
    Granular permissions via Spatie Permissions. Roles are cloned per school so every institution controls its own access model.
  </Card>
  <Card title="WhatsApp Alerts" icon="message">
    Automatic absence and tardiness notifications to tutors via Evolution API with configurable thresholds.
  </Card>
  <Card title="Excel Import & PDF Export" icon="file">
    Bulk-import students from SIGERD-formatted Excel files. Export attendance reports and academic records to PDF.
  </Card>
</CardGroup>

## Getting Started

<Steps>
  <Step title="Clone and configure">
    Clone the repository and copy `.env.example` to `.env`. Set your `APP_URL`, database credentials, and optional third-party service keys.
  </Step>
  <Step title="Run the setup script">
    Execute `composer setup` to install PHP and Node dependencies, generate an application key, run migrations, and build frontend assets.
  </Step>
  <Step title="Start the development server">
    Run `composer dev` to start the Laravel server, queue worker, log tail, and Vite dev server concurrently.
  </Step>
  <Step title="Complete the Owner onboarding">
    Visit `/register` to create the first Owner account and set up the platform. Then use the school wizard to configure your first educational institution.
  </Step>
</Steps>
